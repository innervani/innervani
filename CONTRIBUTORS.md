# Contributors

innerVANI is built by many people. Every contribution is credited in the release notes. This file records the people who started the project.

## Founders

- [Avish Saha](https://github.com/avish-Saha-007), founder and project lead

## Founding contributors

Everyone who contributes before the first release, v0.1 (planned for January 2027), is a founding contributor and is named here for good. Names are added only with each person's permission, and anyone may ask to be listed under a pseudonym or not at all.

- [Himanshu Gupta](https://github.com/himanshug82), community moderator · October 2026

Others will be listed here as they join, with their contribution and the month they joined.

People in independent roles, such as outside readers, raters, reviewers of changes to the core, and community moderators, stay independent of the core team while they serve in those roles. That independence is what makes their work count.

## How contributions are credited

| Contribution | Where it is credited |
|---|---|
| Test cases | The case's `authors` field, and the release notes |
| Code and documentation | The commit history, and the release notes |
| Outside reading, rating, reviewing and moderation | This file and the release notes, with permission |
| Security reports | The security advisory, by name or anonymously |
